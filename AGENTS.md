# fede

fede (Italian and Spanish for "faith") is a minimal, extensible engine that reviews, verifies, repairs and ships agent-written changes, so you can have faith they are safe to merge.

## Agent skills

### Issue tracker

Issues, specs and the wayfinder map live in GitHub Issues on `AntiD2ta/fede`, managed with `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels, unchanged. See `docs/agents/triage-labels.md`.

### Domain docs

One root `GLOSSARY.md`; ADRs are files under `docs/adr/`, indexed by topic in `docs/adr/INDEX.md`. See `docs/agents/domain.md`.
